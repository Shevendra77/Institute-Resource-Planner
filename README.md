# Institute-Resource-Planner

A web-based Institute Resource Planner (IRP) for managing and tracking campus assets. Features role-based access control, real-time inventory monitoring, automated email/SMS alerts, and PDF reporting.

## 🚀 Features
- **Role-Based Access:** Admin and User dashboards.
- **Automated Notifications:** Email and SMS updates via Twilio and JavaMail.
- **Resource Tracking:** Real-time inventory monitoring.
- **Reporting:** PDF report generation.

## 🛠 Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf
- **Database:** MySQL
